## 🐚 Dev

Install dependencies:

```bash
bun run dev:install
```

Create **.env** file in project root (or set environment variables):

```dotenv
BASE_URL=****
LOG_LEVEL=****
TEST_RETRY=****
TEST_TIMEOUT=****
WALLET_ADDRESS=****
```

Test via Vitest UI:

```bash
bun run dev:test
```
